# 読書記録アプリ

読んだ本を記録するシンプルなWebアプリです。

- タイトル・著者・読んだ日・評価(星)・感想メモを登録
- 登録した本は「本棚」として、背表紙が並んだビジュアルで表示
- 検索・並び替え・編集・削除に対応

## 使い方

1. [Node.js](https://nodejs.org/) をインストールする
2. このフォルダで `起動.bat` をダブルクリック(Windows)、または `node server.js` を実行
3. ブラウザで `http://localhost:3100` を開く

## 技術構成

- フロントエンド: HTML / CSS / JavaScript(フレームワークなし)
- バックエンド: Node.js標準ライブラリのみ(`http`, `fs`, `path`)
- データ保存: `books.json`(ローカルファイル)
